FUNCIONAMIENTO Y LIMITACIONES DEL SISTEMA
Plataforma de monitoreo y gestion del riego para microparcelas agricolas
Tlatlauquitepec y Teziutlan, Puebla

1) FUNCIONAMIENTO

1.1 Arquitectura
- Servidor: FastAPI (Python 3.13), organizado por dominios (usuarios, cultivos,
  parcelas, telemetria, recomendaciones y reportes).
- Base de datos: PostgreSQL con migraciones versionadas (Alembic).
- Autenticacion: JWT (Bearer). Aislamiento por usuario: un recurso ajeno
  responde 404.
- Catalogo: nueve hortalizas (ajo, calabaza, jitomate, rabano, zanahoria,
  acelga, lechuga, cilantro y chile) con sus etapas fenologicas.
- Clima: pronostico de siete dias de Open-Meteo, con normalizacion de unidades.
- Redaccion: servicio de inteligencia artificial (Gemini), con modo de
  demostracion que no consume cuota.
- Reportes: PDF generado bajo demanda con ReportLab. No se almacena el binario,
  solo los metadatos en reportes_generados.
- Telemetria: registro de sensores y lecturas con ingesta idempotente.

1.2 Flujo de recomendacion
1. El usuario registra una parcela; la altitud se completa automaticamente si
   no se indica.
2. Registra una siembra asociada a una de las nueve hortalizas. El sistema
   impide ciclos traslapados en la misma parcela.
3. Solicita la recomendacion con siembra_id o con id_hortaliza y dias_siembra.
4. El sistema resuelve la etapa fenologica, consulta Open-Meteo, construye el
   contexto y obtiene la redaccion del servicio de IA.
5. Si hay parcela o siembra asociada, guarda la lectura climatica y la consulta
   en una sola transaccion.
6. Devuelve clima, recomendacion de riego, recomendacion general, alertas,
   nivel de urgencia e identificador de la consulta.
7. El historial queda disponible en /api/v1/ai/historial y el reporte en
   /api/v1/reportes/siembras/{id}.pdf.

1.3 Historial y trazabilidad
- lecturas_climaticas: consulta a Open-Meteo con campos normalizados y el JSON
  original de respaldo.
- consultas_recomendaciones: siembra, parcela, lectura, hortaliza, etapa, dias,
  prompt, respuesta saneada, nivel de urgencia, modelo y modo de demostracion.
- reportes_generados: usuario, siembra, consulta y fecha de emision.
- Integridad referencial con ON DELETE SET NULL o RESTRICT segun el caso.

1.4 Seguridad y robustez
- Los errores hacia el cliente no exponen claves ni credenciales.
- Las alertas y niveles se sanean antes de validarse con Pydantic.
- Las rutas con trabajo bloqueante usan def y se ejecutan en el threadpool.
- La generacion del PDF libera la sesion de base de datos y registra la
  descarga en una transaccion corta.
- Reintentos con espera progresiva ante fallos transitorios de Gemini (429/5xx).
- Modo de demostracion para operar sin cuota ni conexion.
- Validacion de rangos fisicos en la telemetria.

2) LIMITACIONES

2.1 Funcionales
- La recomendacion no incorpora lecturas de sensores: usa el catalogo y el
  pronostico meteorologico.
- No incluye un modelo de prediccion numerica propio; la redaccion la realiza
  el servicio de inteligencia artificial a partir del contexto calculado.
- El catalogo se limita a las nueve hortalizas indicadas.
- El historial solo se genera cuando la consulta se asocia a una parcela o
  siembra. Las consultas con id_hortaliza y dias_siembra no se guardan.
- No hay roles de administrador ni notificaciones proactivas.

2.2 Tecnicas
- Dependencia de internet para Open-Meteo y Gemini; el modo de demostracion
  mitiga el caso.
- La generacion del PDF es intensiva en CPU; se ejecuta en el threadpool, pero
  compite por procesador si se solicita en gran volumen.
- Sin cache de pronostico: cada recomendacion consulta Open-Meteo.
- Pool de PostgreSQL con valores por defecto (5 conexiones y 10 de desborde).
- Sin contenedores ni integracion continua documentada.
- Probado en Windows con PostgreSQL local.

2.3 Configuracion
- El modelo de IA se define en GEMINI_MODEL y debe revisarse periodicamente.
- CORS abierto durante el desarrollo; en produccion debe restringirse.
- Las credenciales viven en .env y no deben versionarse.

3) ESTADO
- Funcionalidad completa: parcelas, siembras, recomendaciones, historial y
  reportes en PDF.
- Suite automatizada de pruebas sobre base de datos en memoria.
